# MVP scope

## The promise

A citizen can understand where their acquisition case is, who currently owns the
next action, and what happens next. An officer can perform an authorized stage
transition, with history preserved.

## Milestone 1: vertical slice

- Seeded citizen and officer accounts
- One seeded project, parcel, landowner, and case
- Citizen case page with six-stage timeline
- Officer assigned-case page
- Validated officer stage transition
- Case-stage history entry for every transition
- Citizen screen refreshes and shows the new stage
- Backend and frontend tests for the critical path

## Milestone 2: demo value

- Parcel map
- Document upload and human-confirmed extraction
- Grievance submission and routing
- Responsibility and bottleneck views
- Audit viewer
- Clearly labelled API Setu fixture

## Milestone 3: only if the demo is stable

- Realtime push without refresh
- Synthetic-data predictive panels
- Additional reports and spatial queries
- UI polish across all administrative roles

## Explicitly excluded

- Land-price or compensation-amount prediction
- AI legal/ownership decisions
- Real payments
- Real government or citizen data
- Production API Setu access
- Five independently maintained frontend applications
